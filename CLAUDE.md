# Portfolio — two builds from one source

The repo serves two versions of the same site:

| Build | Address | Contents |
|---|---|---|
| Full | GitHub Pages, https://7mahfuz.github.io/ (repo root) | Everything, including independent (personal) projects |
| Pro | Cloudflare Pages (generated `pro/` folder) | Same site with **no independent projects**; linked from LinkedIn |

## Rule: edit the root files only; personal projects go inside markers

- `index.html`, `games.html`, `js/`, `css/`, `assets/` and `cv/full.html` are the only source. Any change there shows up in both builds.
- `pro/` and `cv/pro.html` are generated by `scripts/build-pro.js` and are git-ignored. Never edit them by hand.
- Anything about independent projects (MapCars, Motorshut, AykorGPT, VetMart BD, Cumilla Resort and any new one) must sit inside a personal block. That includes freelance-client wording such as "UK" client mentions. Where pro needs different text, put a `pro:` line right after the block:

  ```html
  <!-- personal -->
  <div><dt>Clients in</dt><dd>USA · UK · BD</dd></div>
  <!-- /personal -->
  <!-- pro: <div><dt>Clients in</dt><dd>USA · BD</dd></div> -->
  ```

  ```js
  // personal
  'mapcars': { ... },
  // /personal
  // pro: { ...pro-only line... }
  ```

  Markers sit on their own lines and don't nest. A `pro:` line must be one line.
- Links to `7mahfuz.github.io` are rewritten to `PRO_URL` in the pro build, or dropped while `PRO_URL` is empty. Set `PRO_URL` in `scripts/build-pro.js` or as a Cloudflare environment variable.
- When adding a new independent project, also add its name or domain to `LEAKS` in `scripts/build-pro.js`. The build fails if a `LEAKS` word reaches `pro/`.

## Commands

- `node scripts/build-pro.js`: builds `pro/` and runs the leak check. Run it after every change to confirm the pro build still passes.
- `python scripts/generate_cv.py`: run after changing `cv/full.html`. It rebuilds `Net_CV_MahfuzurRahman.pdf` (full) and `cv/Net_CV_MahfuzurRahman.pro.pdf` (pro). Commit both PDFs.
- `node scripts/verify-v3.js`: static checks for the full site.

## Cloudflare Pages settings

Build command `node scripts/build-pro.js`, build output directory `pro`, framework preset None.
